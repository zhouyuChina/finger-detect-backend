# 全部图片导出功能

## 功能概述

在档案管理页面添加了"全部图片导出"功能，可以将系统中所有检测图片按用户分类导出为ZIP压缩包。

## 功能特性

### 主要功能
- ✅ 在档案管理页面标题栏添加"全部图片导出"按钮
- ✅ 按用户分组导出所有图片
- ✅ 每个用户一个独立文件夹
- ✅ 包含导出信息文件
- ✅ 支持大量图片的批量导出

### 文件结构
```
全部图片_按用户分类_2025-08-11.zip
├── export_info.txt                    # 导出信息文件
├── 用户1_张三_userid1/               # 用户1的文件夹
│   ├── 001_档案名_2025-08-11_normal_85%.jpg
│   ├── 002_档案名_2025-08-11_normal_92%.jpg
│   └── ...
├── 用户2_李四_userid2/               # 用户2的文件夹
│   ├── 001_档案名_2025-08-11_abnormal_78%.jpg
│   ├── 002_档案名_2025-08-11_normal_88%.jpg
│   └── ...
└── ...
```

### 文件命名规则
- **ZIP文件名**: `全部图片_按用户分类_日期.zip`
- **用户文件夹**: `用户名_用户ID`
- **图片文件**: `序号_档案名_检测时间_结果_置信度.扩展名`

## 技术实现

### 前端实现
- 在档案管理页面 (`src/app/archives/page.js`) 添加导出按钮
- 使用fetch API调用后端接口
- 自动下载生成的ZIP文件

### 后端实现
- **API端点**: `POST /api/archives/export-all-images`
- **数据库查询**: 使用Prisma查询所有检测记录
- **图片下载**: 使用node-fetch下载图片
- **文件打包**: 使用JSZip创建压缩包
- **错误处理**: 完善的错误处理和日志记录

### 依赖包
- `jszip`: 创建ZIP压缩包
- `node-fetch`: 下载图片文件

## API接口

### 请求
```http
POST /api/archives/export-all-images
Content-Type: application/json
Authorization: Bearer <token>
```

### 响应
- **成功**: 返回ZIP文件流
- **失败**: 返回JSON错误信息

### 权限要求
- 需要管理员权限
- 包含速率限制
- 需要有效的认证token

## 使用流程

1. **访问档案管理页面**
   - 登录管理员账户
   - 进入档案管理页面

2. **点击导出按钮**
   - 在页面右上角找到"全部图片导出"按钮
   - 点击按钮开始导出

3. **等待下载完成**
   - 系统会显示下载进度
   - 下载完成后自动保存ZIP文件

4. **解压查看**
   - 解压ZIP文件
   - 按用户文件夹查看图片

## 错误处理

### 常见错误
1. **认证失败**: 需要重新登录
2. **网络错误**: 图片下载失败
3. **权限不足**: 需要管理员权限
4. **数据为空**: 没有可导出的图片

### 错误恢复
- 自动跳过无法下载的图片
- 继续处理其他图片
- 在导出信息中记录失败情况
