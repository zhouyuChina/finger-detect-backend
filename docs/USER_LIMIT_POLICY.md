# 用户数量限制策略

## 概述

为了确保系统资源的合理使用和用户体验的优化，我们对每个微信号（openid）可以创建的用户账号数量进行了限制。

## 限制规则

### 基本限制
- **每个微信号最多可以创建 50 个用户账号**
- **包括用户自己的默认账号**
- **其他账号最多 49 个**

### 限制范围
- 微信小程序端创建子用户
- 管理后台创建子用户
- ~~用户注册时创建默认子用户~~（注册时不检查，因为新用户子用户数量为1）

## 技术实现

### 检查逻辑
在创建任何子用户之前，系统会：

1. 查询当前微信用户的子用户总数
2. 检查是否已达到 50 个的限制
3. 如果达到限制，返回错误信息

### 错误响应
当达到限制时，系统会返回：

```json
{
  "success": false,
  "message": "已达到最大用户数量限制（50个），无法创建更多用户账号",
  "code": 400
}
```

## 影响的API接口

### 1. 微信小程序用户创建
- **接口**: `POST /api/miniprogram/users`
- **功能**: 创建新的子用户
- **限制**: 检查子用户数量不超过50个

### 2. 管理后台用户创建
- **接口**: `POST /api/user-management`
- **功能**: 管理员创建子用户
- **限制**: 检查子用户数量不超过50个

### 3. 用户注册
- **接口**: `POST /api/miniprogram/register`
- **功能**: 用户注册时创建默认子用户
- **限制**: 不检查数量限制（新用户注册时子用户数量为1，老用户补建默认子用户时通常不会达到限制）

## 数据库查询

限制检查使用以下 Prisma 查询：

```javascript
const currentSubUserCount = await prisma.subUser.count({
  where: { 
    wechatUserId: wechatUserId
  }
})

if (currentSubUserCount >= 50) {
  // 返回错误信息
}
```

## 用户体验

### 前端提示
当用户尝试创建第51个账号时，会收到清晰的错误提示：
- "已达到最大用户数量限制（50个），无法创建更多用户账号"

### 建议
- 在用户界面中显示当前已创建的用户数量
- 在接近限制时给出提醒
- 提供用户管理功能，允许删除不需要的账号

## 配置说明

### 限制数量
当前限制设置为 50 个，如需调整，需要修改以下文件：
- `src/app/api/miniprogram/users/route.js`
- `src/app/api/user-management/route.js`
- ~~`src/app/api/miniprogram/register/route.js`~~（注册时不检查数量限制）

### 环境变量
可以考虑将限制数量设置为环境变量，便于不同环境下的配置管理。

## 注意事项

1. **数据一致性**: 限制检查在事务中进行，确保数据一致性
2. **性能考虑**: 使用 `count()` 查询而非 `findMany()` 以提高性能
3. **错误处理**: 提供清晰的错误信息，帮助用户理解限制
4. **监控**: 建议监控达到限制的用户数量，评估是否需要调整限制
