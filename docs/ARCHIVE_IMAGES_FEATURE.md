# 档案图片功能

## 功能概述

档案图片功能允许管理员查看和导出特定档案下的所有检测图片。

## 功能特性

### 1. 查看图片
- 在档案管理页面点击"查看图片"按钮
- 跳转到专门的图片查看页面
- 以网格形式展示所有图片
- 支持分页浏览
- 显示图片的检测时间、结果等信息

### 2. 导出图片
- 在档案管理页面点击"导出图片"按钮
- 在图片查看页面点击"导出图片"按钮
- 将指定档案下的所有图片打包为ZIP压缩包
- 文件名格式：`用户名_档案名_日期.zip`
- 图片文件名格式：`序号_检测时间_结果_置信度.扩展名`

### 3. 全部图片导出
- 在档案管理页面点击"全部图片导出"按钮
- 导出系统中所有图片，按用户分类打包
- 文件名格式：`全部图片_按用户分类_日期.zip`
- 每个用户一个文件夹，文件夹名格式：`用户名_用户ID`
- 包含导出信息文件 `export_info.txt`

## 页面结构

### 档案管理页面 (`/archives`)
- 在操作列添加"查看图片"和"导出图片"按钮
- 点击"查看图片"跳转到图片查看页面
- 点击"导出图片"直接下载ZIP文件

### 图片查看页面 (`/archives/images`)
- 显示档案基本信息
- 图片网格展示
- 分页控制
- 导出功能

## API接口

### 导出图片API (`POST /api/archives/export-images`)

**请求参数：**
```json
{
  "archiveName": "档案名称",
  "userId": "用户ID（可选）"
}
```

**响应：**
- 成功：返回ZIP文件流
- 失败：返回错误信息

**功能：**
- 查询指定档案下的所有图片
- 下载所有图片
- 打包为ZIP文件
- 设置合适的文件名

### 全部图片导出API (`POST /api/archives/export-all-images`)

**请求参数：**
```json
{}
```

**响应：**
- 成功：返回ZIP文件流
- 失败：返回错误信息

**功能：**
- 查询系统中所有检测图片
- 按用户分组
- 为每个用户创建文件夹
- 下载并打包所有图片
- 包含导出信息文件

## 技术实现

### 前端组件
- `SafeImage`: 安全的图片显示组件
- 响应式网格布局
- 分页组件
- 文件下载处理

### 后端API
- 使用JSZip库创建压缩包
- 使用node-fetch下载图片
- 文件命名规则
- 错误处理

### 依赖包
- `jszip`: 创建ZIP压缩包
- `node-fetch`: 下载图片文件

## 使用流程

1. **查看图片**
   - 进入档案管理页面
   - 找到目标档案
   - 点击"查看图片"按钮
   - 浏览图片列表

2. **导出图片**
   - 在档案管理页面点击"导出图片"
   - 或在图片查看页面点击"导出图片"
   - 等待下载完成
   - 解压ZIP文件查看图片

3. **全部图片导出**
   - 进入档案管理页面
   - 点击页面右上角的"全部图片导出"按钮
   - 等待下载完成
   - 解压ZIP文件，按用户文件夹查看图片

## 注意事项

1. **权限控制**
   - 需要管理员权限
   - 包含速率限制
   - 认证中间件保护

2. **性能考虑**
   - 大量图片时导出可能需要较长时间
   - 建议分批处理
   - 添加进度提示

3. **错误处理**
   - 图片下载失败时的处理
   - 网络错误的恢复
   - 用户友好的错误提示

4. **文件命名**
   - 避免特殊字符
   - 使用中文文件名
   - 包含时间戳避免重复
