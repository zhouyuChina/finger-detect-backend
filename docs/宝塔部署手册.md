# 宝塔部署手册 — finger-detect-backend

> 适用于手动上传代码到宝塔面板服务器的部署场景。

---

## 一、服务器环境要求

| 组件 | 要求 | 说明 |
|------|------|------|
| 操作系统 | CentOS 7/8、Ubuntu 20.04+ | 推荐 CentOS 7（宝塔兼容性最好） |
| 宝塔面板 | 最新版 | bt.cn 安装 |
| Node.js | v20 LTS 或 v22 LTS | 通过宝塔「软件商店」安装 |
| PostgreSQL | 14+ | 通过宝塔「软件商店」安装 |
| Redis | 6+ | 通过宝塔「软件商店」安装 |
| PM2 | 最新版 | `npm install -g pm2` |
| Nginx | 宝塔自带 | 用于反向代理 |

---

## 二、宝塔面板安装软件

在宝塔「软件商店」中安装以下软件：

1. **Nginx**（通常已预装）
2. **PostgreSQL 14+**（或 15/16）
3. **Redis**
4. **PM2管理器**（宝塔插件）
5. **Node.js版本管理器** — 安装后选择 v20 或 v22 LTS 版本

---

## 三、创建数据库

### 3.1 通过宝塔面板创建

1. 进入宝塔 → PostgreSQL → 添加数据库
2. 填写信息：
   - 数据库名：`finger_detect_db`
   - 用户名：`finger_user`（自定义）
   - 密码：设置一个强密码并记录下来
   - 访问权限：本地服务器

### 3.2 通过命令行创建（备选）

```bash
# 切换到 postgres 用户
sudo -u postgres psql

# 创建用户和数据库
CREATE USER finger_user WITH PASSWORD '你的强密码';
CREATE DATABASE finger_detect_db OWNER finger_user;
GRANT ALL PRIVILEGES ON DATABASE finger_detect_db TO finger_user;
\q
```

### 3.3 确认 Redis 已启动

```bash
redis-cli ping
# 应返回 PONG
```

## 四、上传项目文件

### 4.1 本地打包（在开发机上执行）

在项目根目录下打包，**排除不需要的文件**：

```bash
tar -czf finger-detect-backend.tar.gz \
  --exclude='node_modules' \
  --exclude='.next' \
  --exclude='.git' \
  --exclude='.env*' \
  --exclude='public/uploads/*' \
  --exclude='src/generated/prisma' \
  finger-detect-backend/
```

或者直接在项目目录内打包：

```bash
cd /path/to/finger-detect-backend
tar -czf ../finger-detect-backend.tar.gz \
  --exclude='node_modules' \
  --exclude='.next' \
  --exclude='.git' \
  --exclude='.env*' \
  --exclude='public/uploads/*' \
  --exclude='src/generated/prisma' \
  -C .. finger-detect-backend
```

### 4.2 上传到服务器

方式一：通过宝塔面板「文件」功能直接上传到 `/www/wwwroot/`

方式二：通过 scp 命令：
```bash
scp finger-detect-backend.tar.gz root@你的服务器IP:/www/wwwroot/
```

### 4.3 解压

```bash
cd /www/wwwroot/
tar -xzf finger-detect-backend.tar.gz
cd finger-detect-backend
```

## 五、配置环境变量

在项目根目录创建 `.env` 文件：

```bash
cd /www/wwwroot/finger-detect-backend
```

创建 `.env` 文件，内容如下（根据实际情况修改）：

```env
# 数据库配置
DATABASE_URL="postgresql://finger_user:你的数据库密码@localhost:5432/finger_detect_db"

# Redis配置
REDIS_URL="redis://localhost:6379"

# JWT配置（生产环境务必修改为随机长字符串）
JWT_SECRET="替换为一个随机的长字符串-至少32位"

# 微信小程序配置
WECHAT_APP_ID="你的微信小程序AppID"
WECHAT_APP_SECRET="你的微信小程序AppSecret"

# 文件上传配置
MAX_FILE_SIZE=5242880
UPLOAD_PATH="/uploads"

# 服务器配置
NODE_ENV="production"
PORT=3001
HOST="0.0.0.0"

# 跨域配置（填写你的域名）
ALLOWED_ORIGINS="https://你的域名,http://你的域名"

# 第三方检测服务配置
DETECTION_SERVICE_URL="http://localhost:1008"
DETECTION_SERVICE_ENDPOINT="/predict"

# 限流配置
RATE_LIMIT_WINDOW=60
RATE_LIMIT_MAX_REQUESTS=100

# 日志配置
LOG_LEVEL="info"
```

> **安全提示**：JWT_SECRET 可以用以下命令生成：
> ```bash
> node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
> ```

## 六、安装依赖并构建

```bash
cd /www/wwwroot/finger-detect-backend

# 1. 安装依赖

# 2. 生成 Prisma 客户端
```

## 十、使用 PM2 启动项目

### 10.1 首次启动

```bash
cd /www/wwwroot/finger-detect-backend

# 使用 ecosystem 配置启动
pm2 start ecosystem.config.js --env production

# 保存 PM2 进程列表（开机自启）
pm2 save
pm2 startup
```

### 10.2 验证启动状态

```bash
# 查看进程状态
pm2 status

# 查看日志
pm2 logs finger-detect-backend

# 测试服务是否正常
curl http://localhost:3001
```

### 10.3 常用 PM2 命令

```bash
pm2 restart finger-detect-backend   # 重启
pm2 stop finger-detect-backend      # 停止
pm2 delete finger-detect-backend    # 删除进程
pm2 logs finger-detect-backend      # 查看日志
pm2 monit                           # 监控面板
```

## 十一、配置 Nginx 反向代理

在宝塔面板中：

1. 进入「网站」→「添加站点」
2. 填写域名，PHP版本选择「纯静态」
3. 创建完成后点击「设置」→「反向代理」→「添加反向代理」：
   - 代理名称：`finger-detect-backend`
   - 目标URL：`http://127.0.0.1:3001`
   - 发送域名：`$host`

### 或手动编辑 Nginx 配置

点击站点「设置」→「配置文件」，替换为：

```nginx
server {
    listen 80;
    server_name 你的域名;

    # 文件上传大小限制
    client_max_body_size 20m;

    # 上传文件直接由 Nginx 提供（静态资源加速）
    location /uploads/ {
        alias /www/wwwroot/finger-detect-backend/public/uploads/;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # 静态资源
    location /_next/static/ {
        alias /www/wwwroot/finger-detect-backend/.next/static/;
        expires 365d;
        add_header Cache-Control "public, immutable";
    }

    # 反向代理到 Next.js
    location / {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        proxy_read_timeout 120s;
        proxy_send_timeout 120s;
    }
}
```

### 配置 SSL（建议）

在宝塔面板 → 站点设置 → SSL → Let's Encrypt，申请免费证书并开启强制 HTTPS。

## 十四、常见问题

### Q: 构建时报内存不足

```bash
# 增加 Node.js 内存限制
export NODE_OPTIONS="--max-old-space-size=2048"
npm run build
```

### Q: Prisma 报错 binary target 不匹配

确认 `prisma/schema.prisma` 中 `binaryTargets` 包含服务器对应的平台：

```prisma
generator client {
  provider      = "prisma-client-js"
  output        = "../src/generated/prisma"
  binaryTargets = ["native", "rhel-openssl-1.1.x"]
}
```

- CentOS 7/8：`rhel-openssl-1.1.x`（已配置）
- Ubuntu 20.04+：需要添加 `"debian-openssl-1.1.x"` 或 `"debian-openssl-3.0.x"`

修改后需重新执行 `npx prisma generate`。

### Q: 上传文件权限不足

```bash
chown -R www:www /www/wwwroot/finger-detect-backend/public/uploads
chmod -R 775 /www/wwwroot/finger-detect-backend/public/uploads
```

### Q: PM2 重启后服务未自动启动

```bash
pm2 save
pm2 startup systemd
# 按照提示执行输出的命令
```

### Q: 端口 3001 被占用

```bash
# 查看占用进程
lsof -i :3001
# 或修改 ecosystem.config.js 中的 PORT
```

### Q: 微信小程序无法访问接口

1. 确认域名已在微信公众平台「开发管理」→「服务器域名」中配置
2. 微信要求 HTTPS，确保已配置 SSL 证书
3. 检查 `.env` 中 `ALLOWED_ORIGINS` 是否包含小程序请求来源
